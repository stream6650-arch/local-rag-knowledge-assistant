# Teaching Guide

1. Explain why an LLM does not automatically know private documents.
2. Load and chunk the knowledge base.
3. Convert text into searchable vectors.
4. Retrieve top-k context with cosine similarity.
5. Show source and retrieval score.
6. Discuss retrieval failure and hallucination.

Local extension: sentence-transformers + FAISS + optional local LLM; no cloud key required.
